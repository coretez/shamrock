Features

Built for people who want choice

Multiple engines, one window

Connect OpenAI, Anthropic, Google Gemini, Qwen, Kimi, and other compatible endpoints without leaving the app.

Your keys stay local

API keys are stored on your machine, not on our servers. You keep full control over your credentials and data.

Project-aware context

Organize chats, prompts, files, and guardrails into projects so the agent has the right context every time.

Glass-box reasoning

Inspect what the agent sees and does. No hidden prompts or opaque state between you and the model.

No vendor lock-in

Export threads, settings, and project data anytime. Move your workflow wherever you want.

Fair Source, actually free to use

Licensed FSL-1.1-ALv2: free for all use — personal, educational, and internal commercial work. Only offering Shamrock itself as a competing product or service requires a commercial license, and each release becomes Apache 2.0 two years after publication.

Getting started

How it works

1

Download the app

Grab the latest macOS build (Apple Silicon or Intel) from the GitHub releases page — or clone the repo and npm start.

2

Add your API keys

Store your provider keys locally in the app settings. We never see or collect them.

3

Pick an engine and chat

Create a project, choose a model, and start the conversation. Switch engines whenever you like.

Prefer to run from source?
$ git clone https://github.com/coretez/shamrock.git
$ cd shamrock && npm install
$ npm start
Roadmap

What's stable, what's next

Shamrock is built spec-first: every capability below ships against written objectives with acceptance criteria, and this section tracks the same ledger the repository does.

Stable today
✓  Multi-provider chat
OpenAI, Anthropic, Google, Kimi, Ollama, and any compatible endpoint — switch mid-project.
✓  Three work modes
Work, Documents, and Code — each with its own harness, tools, and rules.
✓  Coding harness
Jailed file & shell tools, approvals priced by irreversibility, git step-commits, automatic code review.
✓  Documents harness
Branded format targets, a versioned document library, and PDF + Excel exports rendered by the app.
✓  Plan-and-execute engine
Alignment questions before work starts, concurrent fan-out collection with merge contracts, bounded re-planning.
✓  The glass box
A live plan rail, token ledger, and per-tool trace — no invisible context engineering.
✓  LLM firewall
Route model traffic through a guard running on your own machine. A refused prompt stops the turn and shows a firewall card — never a chatbot answer — and the card says whether it was refused on the way out or on the way back. The audit records the decision, never the content.
✓  MCP connectors that stay honest
Version-drift detection badges stale skills and tools; one click re-syncs.
On the roadmap
→  Signed installers & auto-update
Notarized macOS builds with a release channel — today Shamrock updates in place from git.
→  Document verification
Claims checked against their sources before a report saves, with a provenance manifest on every deliverable.
→  Widget library
Charts, tables, and callouts rendered by the app from data — the model authors numbers, never markup.
→  Team proxy & shared policy
One gateway for a team: key custody, shared guard policy, central audit — agents inherit the rules.
→  Checkpoint & revert
One-click rollback of an entire turn, built on the step-commit history.

Tracked in the open — see the objectives spec for every item's acceptance criteria and status.

What changed in 0.3.0

The LLM firewall release

  • Route model traffic through a local Trylon guard; blocked prompts stop the turn and never enter the transcript.
  • Distinguish outbound and inbound blocks while keeping the audit metadata-only—decision and correlation ID, never prompt or response content.
  • Preserve completed tool work when a later model call is blocked, and support guards across every OpenAI-compatible connection.
  • Prevent replay of spent MCP OAuth refresh tokens and deduplicate concurrent connection refreshes.
  • Render uploaded HTML correctly and normalize epoch-millisecond timestamps to reduce security-rule false positives.
